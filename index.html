OpenRouter pool history

Each OpenRouter model is served by one or more providers. OpenRouter's model pages show each provider's current price and its price history. What they do not do is tell you when the providers change: a provider joining at many times the cheapest price, a price going up, a provider leaving. This site checks every model's providers every 15 minutes and keeps those changes as a dated record anyone can link to, including providers that have left, which OpenRouter's own history no longer shows. Protect your traffic with OpenRouter's own settings first

  • max_price (opens OpenRouter in a new tab) on the request (or in a preset) is a hard cap: no endpoint above it is used.
  • :floor (opens OpenRouter in a new tab) on the model id, or sort: "price", tries the cheapest input price first (seen on real requests; it can cost more when a request has much output). A throughput or latency preference only moves slower endpoints to the back, so with a price sort a fast, expensive newcomer can still come first.
  • The served provider of every request is on the Logs page, in the response, or in full with the router metadata header.

This record tells you when to look at those settings again. OpenRouter's provider routing docs
